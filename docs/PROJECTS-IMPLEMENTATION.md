# QueryProof and ReleaseGuard delivery

17 November 2026, Asia/Hong_Kong.

QueryProof was a working preview when this implementation session began. The audit found a ratio-denominator false negative, incomplete structural evaluation coverage and import-validation gaps. Those have been addressed, along with declared chained relationship paths. Its public `main` is verified at `fa5760fa6358805f9817fdc37994f752dea2390a`; runtime/evaluator measurements are pinned at `5e7e97b`.

[QueryProof acceptance](https://github.com/ngyathin16/queryproof/blob/main/docs/ACCEPTANCE.md) records 45 tests on clean Windows and Ubuntu checkouts, 21 browser workflow checks, 12 responsive accessibility views, all 60 new and 120 existing expected statuses, 180 diagnostic-query counts and 48 checked repairs. The fresh 144-trial comparison achieved 12/72 repairs without tools and 57/72 with tools. Misleading explanations remain explicitly documented, including among some executed repairs. The desktop 100,000-row benchmark had 774 ms p95 and no failed runs; it is not a laptop measurement or a universal scale claim.

[ReleaseGuard](https://github.com/ngyathin16/releaseguard) now implements real HTTP services, a router with a renewable lease, matched traffic, frozen statistical policy, explicit staged advancement, persistent history, observed withdrawal and reproducible evidence export. The application runs locally without a provider or credential. The public repository is authorized and selected as public by Harold.

ReleaseGuard's 33 repeated live scenarios retained 967,602 requests: three healthy completions, 12 statistical regressions and 18 inconclusive outcomes, with zero fault advancement. Maximum confirmed withdrawal was 329.462 ms, with no violation of the two-second target. Twelve final control reruns retained a further 63,712 requests and matched all source fingerprints. Twenty-eight behavior tests pass. The frozen simulations report 0/200 false regression flags, 100/100 large-regression detections, 0/100 false advancements and 65/200 healthy inconclusive outcomes. Sources, intervals, initial failures and assumptions are retained in its verification and evaluation records.

Both case studies describe actual implemented behavior, personal contribution and AI assistance, and supported scope. QueryProof remains explicit about base-table measures/groups, UTC contracts and fallible model prose. ReleaseGuard remains a synthetic local experiment under stated statistical assumptions. Neither is a hosted executable backend, production deployment or human usability study.

The portfolio orders QueryProof, ReleaseGuard, Relay Desk and IFC-GPT. Counts, next-project navigation and browser routes derive from published content. ReleaseGuard's captioned recording is served as a static asset, with a caption track and responsive video sizing. Repository links provide independently runnable source and full raw evidence.

The production build passed without diagnostics. Local Workers verification passed 18 route/viewport combinations, 48 local links, keyboard/download checks and automated WCAG-tagged scans; all 21 release/deployment tests passed. The final repository and release status is recorded in the delivery update after remote checks.
